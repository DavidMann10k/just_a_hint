## Design implications from source, still to verify in Forever

The modern quest blob code reacts to focus, highlight, and supertracking and checks `questPOI`. The diagnostic therefore creates a separate native frame without Blizzard's quest-blob template or mixin. It makes one explicit `DrawBlob` request and does not acquire standard navigation. This is an implementation choice informed by source; isolation in the installed renderer remains a visual test.

Map parenting uses the modern `GetCanvas()` path and the map's `pinFrameLevelsManager:GetValidFrameLevel("PIN_FRAME_LEVEL_QUEST_BLOB")`; a missing path is recorded instead of guessing a drawing layer. These map internals also require installed-client verification. [Map canvas source](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_MapCanvas/Blizzard_MapCanvas.lua), [frame level manager](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_MapCanvas/MapCanvas_PinFrameLevelsManager.lua).

An API call that returns without throwing is recorded as `call-ok-unverified`, not “area available.” A tester records visible area, no area, or unintended quest areas separately. No polygon data or fallback circle is assumed.

`GetWorldPosFromMapPos` conversions retain their continent IDs, including zero. These are coordinate-space identifiers, not positive UI map IDs. Different continents cannot produce a usable straight-line distance. A nil waypoint records `no-data`; only a separately observed false `HaveQuestData` suggests uncached data. No automatic retries, invented destinations, or navigation side effects are used to fill gaps.

The diagnostic only reads settings. Tester-supplied `normal` / `disabled` labels are retained alongside observed values and notes; they are not automatically verified guidance states.

### Direction preview 0.2.1: native arrow and sticky arrival observed

Version 0.2.0 introduced an independent hint policy controller, current-map destination adapter, minimap renderer, and request/lifecycle orchestration.
