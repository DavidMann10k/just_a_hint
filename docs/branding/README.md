# Branding

The artwork uses painted texture, violet shadows and amber light from the supplied
Forever reference. An unmarked path and a small traveler make exploration the
subject. The gold direction needle connects the image to the addon.

PNG masters retain the generated pixel dimensions. JPG copies use quality 92
encoding without resizing. Use JPG for the banner and social uploads; use PNG
for the icon and transparent marks. The social JPG is 853,036 bytes, below
GitHub's 1 MB limit. Upload it through **Repository Settings → Social preview**.
[GitHub's preview guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)
specifies a 2:1 image, at least 640 × 320 pixels.

Keep **Just a Hint** in title case. The compatibility line is **For World of
Warcraft: Forever**, followed by **Unofficial addon**. Preserve those lines when
cropping a titled image. Use the icon or mark beside an addon name and
compatibility label when the full title will not fit.

The working palette is plum `#201D2B`, antique gold `#D6AE58`, pale gold
`#F3D587` and blue-violet mist. Keep the title legible against a quiet dark
area. Use one direction needle; leave paths and destinations unmarked.

Generated with the builtin OpenAI imagegen tool. [The prompts](prompts.md) record
the briefs and reference roles. The supplied official painting
(`wow-forever-adv.webp`) was used as a style reference and is not included in
these assets. The delivered scenes, traveler, title and emblem were generated
for Just a Hint; they contain no official game logo or faction insignia.
