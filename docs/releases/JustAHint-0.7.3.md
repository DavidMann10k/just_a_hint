# Just a Hint 0.7.3 preview

Target: Forever beta 1.60.1 / build 70205 / interface 16001.

Nearby location pins are half their previous width and height: 12 screen units. They retain the same map coordinates and scale compensation, covering less of the location they mark.

The source bundle includes the illustrated README guide and its five screenshots.

Replace the installed addon files and run `/reload`. First installation requires a client restart. `/jah` opens settings; `/jah restore` restores Blizzard guidance before removal.

Hints require a usable native destination on the current map. Region sampling is approximate; unconfirmed regions use the native quest coordinate. A pin is a location clue, not a guarantee of an exact NPC position.
