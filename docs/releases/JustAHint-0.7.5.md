# Just a Hint 0.7.5 preview

Target: Forever beta 1.60.1 / build 70235 / interface 16001.

When you reach a requested destination, the arrow disappears with a distinct
built-in sound and two green minimap pulses over about 1.2 seconds. More detail
still requires another Hint. Manual clearing, completion, zoning and missing
data stay quiet.

Sound and minimap pulses can be disabled independently in `/jah`. Interrupted
arrival effects do not replay. A new direction request keeps its gold feedback.

Replace the installed addon files and run `/reload`. First installation requires
a client restart. Native arrival sound and pulse checks remain pending.
