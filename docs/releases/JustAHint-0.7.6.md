# Just a Hint 0.7.6 — RC2

Target: Forever beta 1.60.1 / build 70235 / interface 16001.

Arrival now uses the built-in tutorial-notification chime. The arrow clears,
the cue plays once and the minimap rim pulses green twice. Sound and minimap
pulses remain independently configurable in `/jah`.

Replace the installed addon files and run `/reload`. First installation requires
a client restart. The arrival cue and remaining client checks need an in-game
pass before the full release.
