# Just a Hint 0.7.8 — RC4

Target: Forever beta 1.60.1 / build 70235 / interface 16001.

The requested arrow holds at screen center for 0.25 seconds after appearing.
A gold ring pulses once around it and travels with the arrow as it fades.
Flight to the minimap is 25% slower, taking about 0.91 seconds. The center
ring uses the arrow-pulse setting in `/jah`.

Arrival plays one minimap ping and two green minimap pulses.

Replace the installed addon files and run `/reload`. First installation requires
a client restart. The revised animation and remaining client checks need an
in-game pass before full release.
