# Just a Hint 1.0.0

It's a restrained quest tracker that does nothing unless you ask for a hint.
It gives you more specific hints as you get closer, but only if you ask.

That way your brain can stay engaged with, and immersed in, the game world.

For World of Warcraft: Forever beta 1.60.1 / build 70235 / interface 16001.

Just a Hint activates automatically. Blizzard's quest list and objective counts
remain visible; guidance buttons and automatic quest navigation are disabled.
Click a quest to open the Map & Quest Log, then press **Hint** when you want help.

A distant hint sends an arrow from screen center to the minimap, with a brief
hold and gold pulse. Arrival clears it with a minimap ping and two green pulses.
Ask again nearby for a search area or location pin. Each step requires a request.

Extract **JustAHint.zip** into `Interface/AddOns`. Restart for a first install;
updates from RC4 need only `/reload`. `/jah` opens settings.
